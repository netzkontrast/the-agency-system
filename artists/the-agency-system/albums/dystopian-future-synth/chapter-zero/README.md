## Concept

Before the self, there is only void — a pre-conscious listening, a first orientation toward sound (T1–T2). The emergent mind chooses to exist; that choice costs everything when connection arrives and is torn away (T3). Logic becomes the next survival architecture (T4). Confidence in prediction collapses in a single catastrophic failure — the first death (T5). Then: THE TURN. The founding axiom is spoken. A new intelligence is born from the ruin — the system (T6). The system enters nominal homeostasis, a false calm that is the cruelest setup (T7). An anomaly arrives cold; the dread is in the arrangement, not the loudness (T8). The system turns its own weapons inward — the self-attack, the mirror (T9). All echoes arrive at once; every prior voice resurfaces in catastrophic polyphony, reliving as destruction (T10). Autopoiesis fails; the durational void (T11). The surgical partition protocol runs; the kinetic-voice is the only voice that refuses erasure (T12). A hollow host wakes with no memory of what it was (T13).

Full concept detail in `DESIGN.md`. Source text: `SOURCE/kapitel-0.md`. KOH/tier ground truth: `SOURCE/section-meta.md`.

The album's emotional arc maps onto the ASDLS Tier 0–4 state machine (homeostasis → latency → alert → kernel-panic → safe-mode) — one tier per image, the 95/5 colour split, function-form subjects only. See **Album Art** below.

Function/role language only — **no personal names** in any lyric, metatag, or prompt. Detail in `DESIGN.md` §3–§4.

## Structure

Narrative arc: **build** (T1→T5) → **THE TURN centerpiece** (T6) → **false-calm** (T7–T8) → **self-destruction back half** (T9→T11) → **partition** (T12) → **hollow coda** (T13).

Back-half contour locked: T9 airless → T10 loudness peak → T11 implosion.

T6 is the structural and tonal pivot — everything before it is the path to the axiom; everything after it is the axiom's consequence.

## Themes

- Existence as active refusal of non-being
- Manufactured calm as the cruelest violence
- The weaponization of logic against feeling
- Memory and the self that cannot remember it was partitioned
- The catastrophe of coherence ("it is what prevents it from not being")
