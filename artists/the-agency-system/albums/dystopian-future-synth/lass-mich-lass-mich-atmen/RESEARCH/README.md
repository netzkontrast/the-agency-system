# RESEARCH — Source Material for "Lass mich, lass mich atmen" (v3)

This folder contains **source material that informs but does not become** the v3 album. The v3 album is the polyphonic-suite design specified in `../DESIGN.md`; this folder preserves prior craft work as a reference layer that lyric-writer, suno-engineer, and album-conceptualizer can draw on without being bound by.

## What lives here

### `v2-album-README.md`
The full README of the prior **v2 album draft** (formerly at `artists/the-agency-system/albums/dark-industrial/lass-mich-lass-mich-atmen/README.md` on branch `claude/song-idea-breathing-an1Wr`, PR #129, consolidated 2026-05-20).

**Function as research:**
- Documents an alternate album-form for the same title (13-track Mini-Album-Suite under `dark-industrial` genre umbrella)
- Captures the *Industrial-Metal × Doom × Darkwave Hybrid* sonic palette per track, with sub-axes (Witch-house, Slowcore, Dark-Folk, Coldwave, Post-Punk, Dark-Ambient, Ambient-Dream-Pop)
- Names the System-Anteil-Trilogy structure (Beobachter / Container / Kind) that the v3 design re-distributed across different alters

## How to use this folder

**For lyric-writer:**
- Read the v2-track file that conceptually overlaps with the v3 track you're drafting (see mapping above)
- Use its drafted lines as a *prompt-bank*, not as the canonical lyric
- The v3 spec's voice architecture, language-distribution, yellow-protocol, and polyphony rules override v2 in case of conflict

**For suno-engineer:**
- v2 tracks have detailed Style Box and Sonic Profile entries — these are reference templates for the v3 per-track sonic palette in `../DESIGN.md` §6.2
- v3's BPM and industrial-metal % per track differ from v2; trust v3's grid

**For album-conceptualizer:**
- v2 is an alternate-form record of the same album-title. It is not the album being conceptualized; v3 DESIGN.md is. Treat v2 as **prior-art** in Phase 1 (Concept & Thesis) and Phase 3 (Research Synthesis)

**Do not write to this folder during album production.** It is read-only research material. Any new research goes to `../DESIGN.md` or a new sibling file at the album root.
