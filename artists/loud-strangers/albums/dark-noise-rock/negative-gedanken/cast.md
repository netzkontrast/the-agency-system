# Cast — Loud Strangers · „Negative Gedanken"

Loud Strangers ist ein **Single-Voice Konzept-Projekt**. Die „Stimme" des Albums ist nicht ein Plural von Alters oder eine multi-narrator Konstruktion — sie ist *ein Bewusstsein*, dessen innere Erfahrung sich über die sieben Tracks in vier POV-Aspekte aufbricht. Jeder Aspekt unten ist eine Perspektive, in der der lyric-writer für einen gegebenen Track sitzen kann. **Es sind nicht verschiedene Charaktere. Es ist dieselbe Person, gebrochen.**

## DNA-Isolation (MANDATORY)

Dieses Album teilt **keine DNA** mit `children-of-agatha` (atmospheric-dark-folk, dark-trip-hop) oder `the-agency-system`. Plurality, alter-coded Vocal-Register, witness-layer-Scaffolding und ensemble-polyphony aus cross-project overrides (`lyric-writing-guide.md`, `voice-craft-principles.md`, `suno-preferences.md`) sind **nicht anzuwenden**.

Wenn ein einzelner Track eine zweite Stimme verlangt (z.B. den Stimmen-Chor in T2), ist das eine track-level Produktionsentscheidung — kein Default-Scaffold und kein Hinweis auf eine Plural-Identität.

## Die vier Aspekte

### 1. Die Hülle

> Die äußere, weiter funktionierende Hülle. Steht sozial noch zusammen, während innen alles zerfällt. Sie geht zur Arbeit, sie spricht in Sätzen, sie nickt im Gespräch. Halb-bewusst, dass sie täuscht.

| | |
|---|---|
| **Voice Register** | flach, kontrolliert, leise aber konversationell. Leicht erzwungene Heiterkeit, wenn nötig. |
| **Tonality** | numb, leicht roboterhaft, mittlere Distanz im Blick. Kein Pathos. |
| **Lexicon** | sachlich, transaktional, „ich" aber nie „wir". Funktions-Vokabular. |
| **Suitable POV for** | **T1** (Bevor sie kamen — die Stille), **T6** (Dauerschleife — der mechanische Loop) |
| **Production Note** | mono-vocal, close-mic, kaum Effekte. In T1 mit aufsteigendem Rauschen unter der Stimme. |

### 2. Die Stimmen (Chor)

> Die fremden, lauten Antagonisten selbst. Plural, herablassend, lauter als sie. Sie benutzen ihr eigenes Vokabular gegen sie — „blöd", „nichts wert", „Komparsin", „zu nichts zu gebrauchen". Manchmal schreien, manchmal flüstern, nie an sich zweifelnd.

| | |
|---|---|
| **Voice Register** | hart, aggressiv, multitracked als Chor. Nie als sanfter Witness, nie als therapeutische Stimme. Das sind die Bullies im Kopf. |
| **Tonality** | hochmütig, schneidend, mit ironischer Glätte. |
| **Lexicon** | reduktiv, punitiv, zweite Person — „du bist", „du kannst nicht", „wie blöd bist du". |
| **Suitable POV for** | **T2** (Loud Strangers — Titeltrack, Peak-Übernahme), **T3** (Hintergrund-Flood) |
| **Production Note** | **Einziger Aspekt, in dem multi-voice genre-gerechtfertigt ist** (Chor von Stimmen). Andere drei Aspekte bleiben mono-vocal, außer der Track verlangt explizit anders. Stereo-spread weit, layering aggressiv, kein Verzeihen im Mix. |

### 3. Der Beobachter

> Die meta-bewusste Instanz, die alles sieht — auch die Übernahme selbst — ohne eingreifen zu können. Spricht in Präsens, exakt, deskriptiv. Fast forensisch. Bleibt durchgehend lucid, auch im Versinken.

| | |
|---|---|
| **Voice Register** | intimate, dry, close-mic'd. Spoken-word-Range; **nie** gesungen. |
| **Tonality** | klinisch, präzise, ohne Selbstmitleid. Nicht warm, nicht kalt — beobachtend. |
| **Lexicon** | klinisch-deskriptiv: „ich beobachte mich", „ich sehe", „ich erlebe", „es passiert mir". |
| **Suitable POV for** | **T4** (Wahres Gesicht — Spoken-Word-Centerpiece), Hintergrund in **T3** (Beobachter sieht das schwarze Meer) |
| **Production Note** | Trocken, kein Reverb-Heroismus. Drone-bed darunter, nicht über der Stimme. In T4: fast a-cappella mit Sub-Bass-Drone. |

### 4. Das verlorene Ich / Frohnatur (Memoria)

> Das vergrabene, „eigentliche" Ich — die Person vor der Krankheit. Im Quelltext: „Ich bin eigentlich so eine Frohnatur / Ein eigentlich so glücklicher Mensch". Erinnert als hoffnungsvoll, fähig. Jetzt nahezu unhörbar. Taucht nur in Traumzuständen (T5) oder in fragilen Coda-Momenten (T7) auf.

| | |
|---|---|
| **Voice Register** | weicher, melodisch, atemtragend. Nie triumphierend. |
| **Tonality** | sehnsüchtig, brüchig, mit Hauch. Nicht traurig — distanziert hoffnungsvoll. |
| **Lexicon** | Träume, Licht, „ich war", „ich könnte", Konjunktiv und Vergangenheit. In T7: ein einziges „ich" im Präsens, leise. |
| **Suitable POV for** | **T5** (Paradise — die Dream-Pop-Bridge), **T7** (Funke — der vorsichtige Funke + Loop) |
| **Production Note** | shoegaze-reverb in T5 (Traum-Distanz); in T7 zunächst trocken intim, dann mit aufbauendem Post-Rock-Wall verzehrt, bis nur noch Noise bleibt. |

## Was dieses Album NICHT ist

- **Keine Plurality-Narrative.** Loud Strangers ist *ein* Bewusstsein, das sich refraktiert. Die vier Aspekte sind Perspektiven, keine Identitäten.
- **Die Stimmen sind kein Alter.** Sie sind ein intrusives Symptom, das Vokabular-Form annimmt. T2 ist das Symptom als Track, nicht eine zweite Person, die singt.
- **Der Beobachter ist kein Witness-Self im Trauma-Therapie-Sinn.** Er ist nur der Teil der Erzählerin, der lucid geblieben ist.
- **Das verlorene Ich ist kein Inner-Child.** Es ist die *Frohnatur* — der Mensch, der sie vor der Krankheit war, jetzt fast unhörbar.

## Für lyric-writer

Beim Schreiben eines Tracks: **wähle einen Primary POV**. Bleib drin. Wenn du einen Secondary POV einlässt (z.B. background-din in T3), markier das in der Track-Datei explicit — das ist eine Production-Entscheidung, kein „auch mal kurz eine andere Stimme sein".

Sprich aus dem Lexikon des Aspekts. Wenn du in „Die Hülle" sitzt, kein „Konjunktiv". Wenn du in „Das verlorene Ich" sitzt, kein „du bist nichts wert".

Wenn der Track-Charakter wirklich verlangt, dass die Erzählerin zwischen zwei Aspekten wechselt (z.B. T6: Hülle wiederholt die Worte der Stimmen) — markier den Wechselpunkt strukturell (eine Bridge, eine Stanza-Grenze). Kein nahtloses Verschmelzen.
