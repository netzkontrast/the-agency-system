# Work we studied

Films and posts by other people that taught this skill something. Each one belongs to its maker, linked here. Nothing of theirs is in this repo: no frames, no prompts, no code. Every style is taught by its own written recipe in `references/styles/` and proven with our own two preview frames.

If you made one of these and want the entry changed or removed, open an issue.

## Adding to this list

When someone shares a reference worth learning from: study it (`scripts/contact-sheet.sh`), write what it teaches in your own words, add a row here with a link to the maker, and if it is a new look, write a style file and render its two preview frames. Never copy the work itself.
